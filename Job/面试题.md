## ✅ Part 1: 技术类问题（简洁回答模板）

---

### ❓**1. What is the difference between an interface and an abstract class in Java?**

**✅ Answer:**

> An interface only has method definitions, while an abstract class can have both method definitions and implementations. I use interfaces for flexibility and abstract classes when I want to share some code.

---

### ❓**2. What is dependency injection in Spring?**

**✅ Answer:**

> It means Spring gives objects their dependencies automatically. It helps me write clean and flexible code, without creating objects manually.

---

### ❓**3. How did you use MyBatis in your project?**

**✅ Answer:**

> I used MyBatis to map SQL queries to Java methods. I also used dynamic SQL tags like `<if>` and `<foreach>` to write flexible queries.

---

### ❓**4. Why did your team use message queues (MQ)?**

**✅ Answer:**

> We used MQ to make services loosely connected. It helps handle high traffic and makes the system more stable when some parts are slow or offline.

---

### ❓**5. What is the advantage of microservices in your project?**

**✅ Answer:**

> Microservices let us split the system into smaller parts. Each part can be developed and deployed alone. It's easier to manage and test.

---

### ❓**6. What tools did you use for version control and CI/CD?**

**✅ Answer:**

> We used Git for version control and Jenkins for continuous integration. When I push code, Jenkins builds and tests it automatically.
