### 2. WDL 字符串交替重组
一个字符串inputStr中只含有WDL三种字母，需要生成新字符串，从inputStr取出一个W，然后取出一个D，然后取出一个L，往后添加，如果没有就添加其它的，比如输入LDWDL，输出WDLDL

**解题思路：** 这道题最稳的解法是**计数器/桶排序思想**。
1. 先用一个哈希表或者大小为 3 的数组，统计出输入字符串中 'W'、'D'、'L' 各自出现的次数。
2. 用一个 `while` 循环，只要总字符还没凑齐，就按照 `W -> D -> L` 的顺序依次去检查计数器。
3. 如果当前轮到了 'W' 且 'W' 的剩余数量 > 0，就追加 'W' 并让其数量减 1；如果为 0，则跳过，继续看下一个字母。

### 3. N x N 矩阵顺时针螺旋排序
- **LeetCode 缝合题：** **54. Spiral Matrix (螺旋矩阵 I)** + **59. Spiral Matrix II (螺旋矩阵 II)**

把 n x n 矩阵元素按照顺时针排好序后输出

注意边界控制，用while控制比用for好得多，加上top, bottom, right, left就好控制得多，以及从右往左和从下往上容易造成重复，需要判断剩余行大于1行才需要从右往左，剩余列大于1列才需要从下往上，否则这种情况跟顺走就重复了。
