**位运算操作：**
按位与&，或|，异或^(不同为 1，相同为 0)，左移右移

**位运算常见套路：**
**`n & 1` 常常用来提取最后一位**，替代n%2。
异或`x^x = 0; x^0=x;` 并且支持结合律，所以可用来找夹杂在某些双数个数元素中的单数元素。
异或自反性： `a ^ b = c`，那么必定有 `a ^ c = b` 以及 `b ^ c = a`。可用于知道其中两个值推倒第三个值。
 `n & (n - 1);`直接把二进制中最右边的那个 `1` 变成 `0`。可用于快速统计1的个数，判断是否为2的幂
 `n & (-n);` 保留最右边的 `1`，把其他的 `1` 全变成 `0`。

**避坑：**
位运算的优先几极低，必须加括号！ `if ((n & 1) == 0)`；
负数右移后使用`>>`会将空出的位补1，保持负号；如果要右移判断0，可以使用逻辑右移`>>>`无脑补0；


常见题型：不需要额外空间的方法，就往位运算上套

### [338. 比特位计数](https://leetcode.cn/problems/counting-bits/)
[338. Counting Bits](https://leetcode.com/problems/counting-bits/)
给你一个整数 `n` ，对于 `0 <= i <= n` 中的每个 `i` ，计算其二进制表示中 **`1` 的个数** ，返回一个长度为 `n + 1` 的数组 `ans` 作为答案。
```
示例 1：

输入：n = 2
输出：[0,1,1]
解释：
0 --> 0
1 --> 1
2 --> 10
```

题解1：逐位运算。通过%2余数判断其二进制从右往左的每一位是否为1。比如：13（二进制是 1101），第一步判断最后一位1，即用`13%2 == 1`，然后判断剩下的110的最后一位，即第二轮变成`13/2`或者`13>>1`，再进行最后一位%2判断。
```java
while(n != 0) {  
    // 【优化】：用位运算替代低效的取模和除法  
    if ((n & 1) == 1) cnt++; // 等效于 n % 2 == 1    
    n = n >> 1;              // 等效于 n / 2
}
```

题解2：dp。如果是偶数n，它转换成二进制只比n/2末尾多了一个0，不影响1的个数；而奇数比它减一的偶数多了1（同时也是比它的一半多了个1）。所以有`rlt[i] = rlt[i >> 1] + (i & 1);`

### [136. 只出现一次的数字](https://leetcode.cn/problems/single-number/)
[136. Single Number](https://leetcode.com/problems/single-number/)
给你一个 **非空** 整数数组 `nums` ，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。
你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。
**示例 1 ：**
输入：nums = [2,2,1]
输出：1

题解：利用异或性质`x^x = 0; x^0=x;` 并且支持结合律。一次循环将所有结果进行异或，最后的值就是落单的数字。

### [1318. 或运算的最小翻转次数](https://leetcode.cn/problems/minimum-flips-to-make-a-or-b-equal-to-c/)
[1318. Minimum Flips to Make a OR b Equal to c](https://leetcode.com/problems/minimum-flips-to-make-a-or-b-equal-to-c/)

给你三个正整数 `a`、`b` 和 `c`。
你可以对 `a` 和 `b` 的二进制表示进行位翻转操作，返回能够使按位或运算   `a` OR `b` == `c`  成立的最小翻转次数。
「位翻转操作」是指将一个数的二进制表示任何单个位上的 1 变成 0 或者 0 变成 1 。
**示例 1：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2020/01/11/sample_3_1676.png)
```
输入：a = 2, b = 6, c = 5
输出：3
解释：翻转后 a = 1 , b = 4 , c = 5 使得 a OR b == c
```

题解：分类讨论逐位运算。维护cnt计数，while循环条件为a,b,c某一方不为0，如果c的最后一位为1，那么只要a或b其中某一位为0，则cnt++；若c的最后一位为1，如果a和b最后一位都为1，则cnt+=2（或者这里可以使用cnt+=bitA+bitB直接跳过判断），否则如果有任意一方为1，另一方为0，则cnt++；其余条件则符合或规则，cnt不变；运算完一轮后运算下一位，即a,b,c都右移一位。
