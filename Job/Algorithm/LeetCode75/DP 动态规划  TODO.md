DP无固定模板，核心是找到状态转移方程。

### 📡 一、 如何一眼识别出这是 DP 题？

1. **题目问的是“极值”或“计数”：**
    
    - 提问方式通常是：“最大/最小收益”、“最少花费”、“最长子序列”、“一共有多少种方法”、“是否可行（True/False）”。
        
    - _(注：如果题目要求你打印出所有具体的组合/路径，那就是回溯；如果只求数量或极值，99% 是 DP。)_
        
2. **存在“无后效性”（只看眼前，不问过往）：**
    
    - 当前的状态只跟前一个或前几个状态有关。比如走到第 10 阶台阶的方法数，只等于走到第 9 阶 + 第 8 阶的方法数，**我根本不在乎你是怎么走到第 9 阶的**。
        

### 🧩 二、 推导方程的终极心法：“最后一步分析法”

不要一上来就去想整个数组怎么变化。**死死盯住“最后一个状态（比如 `dp[i]`）”，然后问自己：“在到达 `i` 之前，我上一秒在哪？”**

#### 1：一维爬楼梯类（简单递推）

- **特征：** 每次只能走固定的步数（比如 1 步或 2 步）。
    
- **最后一步分析：** 想到达 `i`，我上一秒只能在 `i-1` 或 `i-2`。
    
- **题目对应：**
    
    - **第 N 个泰波那契数：** `dp[i] = dp[i-1] + dp[i-2] + dp[i-3]`
        
    - **使用最小花费爬楼梯：** `dp[i] = Math.min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])`
        

#### 2：选与不选类 / 状态机（经典一维）

- **特征：** 面对当前元素，你只有两种选择：**“要”** 或者 **“不要”**。
    
- **最后一步分析（以打家劫舍为例）：**
    
    站在第 `i` 个房子前：
    
    - **选（偷）：** 那我绝对不能偷 `i-1`，所以收益是 `dp[i-2] + nums[i]`。
        
    - **不选（不偷）：** 那我的收益就和走到 `i-1` 时一样，即 `dp[i-1]`。
        
    - **方程：** `dp[i] = Math.min(偷, 不偷)`。
        
- **题目对应：**
    
    - **打家劫舍：** 典型的选与不选。
        
    - **买卖股票含手续费：** 高阶状态机。每天都有“持有股票 (`hold`)”和“不持有股票 (`cash`)”两个状态在互相转换。
        

#### 门派 3：二维网格类 (Grid DP)

- **特征：** 给一个二维矩阵，只能向下或向右走。
    
- **最后一步分析：** 想到达格子 `(i, j)`，我上一秒只能在它**上面 `(i-1, j)`** 或者 **左边 `(i, j-1)`**。
    
- **题目对应：**
    
    - **不同路径：** `dp[i][j] = dp[i-1][j] + dp[i][j-1]`。
        

#### 门派 4：双字符串类 (最难，二维 DP 巅峰)

- **特征：** 给你两个字符串 `s1` 和 `s2`，求它们的最长公共子序列、编辑距离等。
    
- **最后一步分析：** 定义 `dp[i][j]` 为 `s1` 的前 `i` 个字符和 `s2` 的前 `j` 个字符的结果。盯着这两个字符串的**最后一个字符 `s1[i-1]` 和 `s2[j-1]`** 看：
    
    - **如果它俩相等：** 皆大欢喜，各自退一步。`dp[i][j] = dp[i-1][j-1] + 1`。
        
    - **如果它俩不相等：** 必须做取舍（删除、替换或跳过）。
        
- **题目对应：**
    
    - **最长公共子序列：** 不相等时，要么抛弃 `s1` 的末尾，要么抛弃 `s2` 的末尾，取最大值 `Math.max(dp[i-1][j], dp[i][j-1])`。
        
    - **编辑距离：** 增、删、改三种操作取最小值。
        

### 💡 三、 那些容易“翻车”的套路细节

1. **初始化边界填错：** DP 最容易报错的就是 `ArrayIndexOutOfBoundsException`。写代码前一定要在纸上画一下 `dp[0]` 和 `dp[1]` 是什么。对于二维字符串 DP，通常需要多开一行一列（长度设为 `len + 1`），用 `dp[0][0]` 代表空串的情况，能省去无数的边界 `if-else`。
    
2. **空间压缩（进阶）：** 如果你发现 `dp[i]` 永远只依赖于 `dp[i-1]` 和 `dp[i-2]`，那么你根本不需要 `new int[n]`，只需要 2 个变量**滚动**更新即可。这能把空间复杂度从 $O(N)$ 降到 $O(1)$。
    

Tips:
1. 有时dp数组可以比给定数组多1位，便于操作。以及这个可以视题目情况而定，多一位少一位都无伤大雅，主要是根据状态转移方程，不要弄错位就行。
