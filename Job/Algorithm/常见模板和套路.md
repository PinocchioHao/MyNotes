| **场景需求**                                 | **最佳数据结构**                    | **原因**                                    |
| ---------------------------------------- | ----------------------------- | ----------------------------------------- |
| 只要统计次数，或者判断某元素出没出现过                      | **HashMap / HashSet**         | $O(1)$ 查找，最直观。                            |
| 字符集固定（如全是小写字母、全在 ASCII 码内）               | **`int[26]` 或 `int[128]` 数组** | 速度最快，内存最小，完全可以平替 Map。                     |
| **需要动态变化地求最大/最小值**（比如：每吐出一个元素，剩下的要重新比大小） | **PriorityQueue (堆)**         | **无脑选它**。不用自己写排序，系统自动 $O(\log N)$ 帮你动态排序。 |

### BFS

```Java
public static void bfs(TreeNode node){
	Queue<TreeNode> queue = new LinkedList<>();
	queue.add(node);

	while(!queue.isEmpty()){
		int numsOfLevel = queue.size();
		for(int i = 0; i < numsOfLevel; i++){
			TreeNode tmp = queue.poll();
			System.out.println(tmp.val);
			if(tmp.left!=null){
				queue.add(tmp.left);
			}
			if(tmp.right!=null){
				queue.add(tmp.right);
			}
		}
	}

}
```


### DFS树的深度
```java 
// 自底向上，不带状态
public static int maxDepth(TreeNode root) {  
    if (root == null) return 0;  
    int leftDepth = maxDepth(root.left);  
    int rightDepth = maxDepth(root.right);  
    return Math.max(leftDepth, rightDepth) + 1;  
}

// 自顶向下，带着状态递归，每向下一层就把depth+1传给孩子，找到叶子就把depth报出来  
public int dfs(TreeNode root, int depth){  
    if (root==null) return depth;  
    return Math.max(dfs(root.left,depth + 1), dfs(root.right, depth +1));  
}

```

### 绑定两个数组并排序
注意这里不是将其2行n列矩阵化，而是将其转换为一个n行2列的pair对，这样能保证每行独立构成一个整体，每行调换顺序，元素两两绑定
```java
// 1. 强行组合：把 nums1 和 nums2 的元素打包成一个二维数组
        // pairs[i][0] 存 nums1[i]，pairs[i][1] 存 nums2[i]
        int[][] pairs = new int[n][2];
        for (int i = 0; i < n; i++) {
            pairs[i][0] = nums1[i];
            pairs[i][1] = nums2[i];
        }

        // 2. 核心排序：按照 nums2 的值（也就是 pairs[i][1]）从大到小排序
        Arrays.sort(pairs, (a, b) -> b[1] - a[1]);
```


### 二分查找
**一定要注意边界！！！**

全闭区间交叉法(“左神模板”)：
##### 精确匹配
```java
// 搜索区间：[left, right] （左闭右闭）
int left = 0;
int right = nums.length - 1; // 因为是闭区间，right 必须是真实的最后一个元素索引

while (left <= right) { // 关键：必须是 <=。因为 left == right 时，那个唯一的元素还没被检查！
    
    int mid = left + (right - left) / 2;
    
    if (nums[mid] == target) {
        return mid; // 找到了，直接收工
    } else if (nums[mid] < target) {
        left = mid + 1; // mid 太小了，往更大的半边收缩
    } else {
        right = mid - 1; // mid 太大了，往更小的半边收缩
    }
}
return -1; // 找遍了也没有
```

##### 寻找左边界（第一个>=target的位置）
```java
int left = 0, right = arr.length - 1;
int ans = -1; // 便于记录
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (arr[mid] >= target) {
	    // mid所在元素只要>=target就记录进ans，随后右边界收缩
	    // 最后ans记录的一定是第一个>=target的元素 
        ans = mid;      // 当前位置符合，先记下来！
        right = mid - 1; // 继续往左逼近，看有没有更靠左的符合条件的位置
    } else {
        left = mid + 1;  // 不达标，往右找
    }
    
    // 最终左右边界都会收缩一致，成为left == right，此时为第一个>=target的位置
    // 注意最最最后这一步执行完后退出循环，是left>right (left = right + 1)
    // 常规情况下，如果找得到这个元素，那么最终结果ans = left = right + 1，但是不能无脑返回left，因为ans还起了一个保护作用，如果找不到，应该返回-1，而left则不能表现
}
return ans; 
// 循环结束，ans 里记录的就是最后一个被记下来的达标者，也就是最左边的那个！
```


##### 寻找右边界（最后一个<=target的位置）
```java
int left = 0, right = arr.length - 1;
int ans = -1; // 记录
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (arr[mid] <= target) {
        ans = mid;      // 当前位置符合，先记下来！
        left = mid + 1;  // 继续往右逼近，看有没有更靠右的符合的位置
    } else {
        right = mid - 1; // 不达标，往左找
    }
}
return ans; 
// 循环结束，ans 里记录的就是最后一个被记下来的达标者，也就是最右边的那个！
```

其实寻找右边界还可以通过左边界函数反推，左边界的左边元素其实就是最后一个<target的元素；如果我们要用左边界模板找最后一个<=target的元素，还可以找第一个>=target+1的元素，然后这个元素左边的位置就是最后一个<=target的元素（前提是整数数组）。

### 🧠 动态规划到底有没有“固定模板”？

**答案是：代码结构上没有，但思维模式上有绝对的“五步套路”！**

回溯法和二分查找，我们可以写出一个骨架代码（比如 `while(left < right)` 或者 `backtrack()`），你往里面填肉就行。但是 DP 的代码有时候只是一个 `for` 循环，有时候是两个嵌套 `for` 循环，外观千变万化。

不过，解题的**心法套路**是绝对固定的，在刷 DP 专题时，无论多难的题，你只要在脑子里强制自己回答下面这 5 个问题（业内俗称“DP 五部曲”），代码自己就会流出来：

1. **状态定义（最难的一步）：** `dp[i]` 到底代表什么物理意义？（比如你 746 题注释写的“到达当前位置的代价”）。
    
2. **状态转移方程（核心灵魂）：** `dp[i]` 是怎么从前面的状态推导过来的？（比如你写的 `dp[i] = Math.min(...)`）。
    
3. **初始化：** 最开始的那几个基石是什么？（比如 `dp[0] = 0`, `dp[1] = 0`）。
    
4. **遍历顺序：** 是从前往往后遍历，还是从后往前遍历？（1D DP 通常是从前往后）。
    
5. **返回值：** 最终的答案藏在 `dp` 数组的哪里？（比如 `dp[dp.length - 1]`）。
