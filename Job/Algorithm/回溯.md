纯暴力搜索，但是可以通过剪枝稍微提高效率；虽然暴力，但是有些问题使用for循环不能解决，只能回溯

回溯逻辑通常写在递归函数调用之后的逻辑。


适用问题：
1. 组合问题，没有顺序
2. 排列问题，有顺序
3. 切割问题，比如字符串切割成多少种，或者可能加限定条件，比如切成多少回文子串
4. 子集问题，比如列出一个集合的所有子集
5. 棋盘问题，N皇后，数独等


解回溯问题的时候抽象成回溯的N岔树形结构，N一般是每轮处理的集合大小，树深度一般是递归层数。



所有回溯问题，都可以抽象为一棵**N 叉树**：
- **树的深度（纵向）：** 决定了递归的层数（往往对应你要找的组合长度 `k`，或者字符串长度）。
- **树的宽度（横向）：** 决定了 `for` 循环的次数（当前层有多少个选项可以选）。
    
**万能模板：**

```java
// 绝大多数回溯函数返回类型为 void，靠操作传入的全局变量 res 和 path 来记录结果，还需要传整体数据集以及当前位置
public void backtrack(参数) { 
    // 1. 终点拦截（到达树的叶子节点）
    if (终止条件（如 path.size() == k 或 index == str.length） ) {
        // 【天坑注意】：必须 new 一个新对象存入结果集！
        res.add(new ArrayList<>(path)); 
        return;
    }

    // 2. 遍历当前层的所有选择
    for (选择 : 本层集合中元素) {
        // 剪枝操作（可选）：如果发现当前选择肯定没戏，直接 continue 或 break
        if (不合法或没必要) continue; 

        // 3. 做选择（记录路径、扣减目标值、更新状态）
        path.add(选择);

        // 4. 递归下探（进入下一层）
        // 注意参数的变化：比如 startIdx + 1，或者 target - nums[i]
        backtrack(路径，选择列表); 

        // 5. 撤销选择（回溯核心：恢复现场！）
        // 刚才加进去的元素已经穷尽了它的所有可能，必须踢掉，腾出位置给下一个兄弟节点
        path.remove(path.size() - 1); 
    }
}
```

相关题型：排列问题、组合问题、子集问题。

|**门派题型**|**核心特征**|**for 循环起点控制**|**结果收集时机**|
|---|---|---|---|
|**组合 (Combinations)**|顺序无关。`[1, 2]` 等同于 `[2, 1]`。|传入 `startIdx`。下一层从 `i + 1` 开始，坚决不回头。|到达叶子节点（满足指定长度或目标和）。|
|**子集 (Subsets)**|收集所有节点。可以看作是无限制条件的组合。|传入 `startIdx`。下一层从 `i + 1` 开始。|树的**每一个节点**都要收集（通常在函数第一行直接 add）。|
|**排列 (Permutations)**|顺序相关。`[1, 2]` 不同于 `[2, 1]`。|每次都从 `0` 开始！需要 `boolean[] used` 数组跳过已选元素。|到达叶子节点（路径长度等于原数组长度）。|

注意回溯中的值传递和引用传递，113题VS1448题

回溯过程中对对象的操作，比如 `resList.add(new ArrayList(path))` ，每一轮之后resList会被增加一个path数组当前的副本，这里不要直接`add(path)`因为`path`会在回溯过程中被改变，最后变成一个空数组在结果集中。而这里每一层的回溯操作也值得注意，需要在`dfs(root.left); dfs(root.right);` 操作之后，`path.removeLast()`将当前结果移除，从而回溯到父节点进行另一个分支的操作。
```java
	public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        List<Integer> path = new ArrayList();
        List<List<Integer>> rlt = new ArrayList();
        dfs(root, targetSum, path, rlt);
        return rlt;
    }

    public void dfs(TreeNode root, int targetSum, List<Integer> path, List<List<Integer>> rlt){
        if (root == null) return;
        path.add(root.val);
        int sub = targetSum - root.val;
        if (root.left == null && root.right == null){
            // 需要添加一个新的数组，如果add(path)则加入path的引用，最后结果就是path最后会被处理为空数组
            if (sub == 0) rlt.add(new ArrayList(path));
        }
        dfs(root.left, sub, path, rlt);
        dfs(root.right, sub, path, rlt);
        // 回溯，回到上一层之后要舍弃掉当前这层加入的节点，即删除path末尾元素
        path.removeLast();
    }
```


而值传递则不用多虑，每层传的值都是当前这层的。以下maxVal即使进入下一层，可能会发生修改，但是在本层还是记录的是对它的快照。
```java
    public int dfs (TreeNode node, int maxVal) {
        if (node == null) return 0;
        int currCnt = 0;
        if (node.val >= maxVal) {
            currCnt = 1;
            maxVal = node.val;
        }
        return currCnt + dfs(node.left, maxVal) + dfs(node.right, maxVal);
    }
```
