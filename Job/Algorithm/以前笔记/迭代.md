步进不确定的，用while而不要用for\

**while使用注意事项：**
while中嵌套while可以方便高效一次性处理或跳过一段逻辑，处理去重或分段时比较好，但是要注意控制变量范围和条件，否则容易出现越界。
```java
int i = 0;
while (i < n) {
    int start = i;
    // 内层 while 一溜烟跑完所有相等的数
    while (i + 1 < n && nums[i] == nums[i+1]) {
        i++;
    }
    // 此时 [start, i] 就是一段连续相等的区间
    System.out.println("Found range: " + start + " to " + i);
    i++; // 准备下一段
}
```

以及while的循环变量非常灵活，一定要注意当前循环的循环变量在被修改后是否有被其它变量给使用，需要注意此时的这个变量到底代表当前循环还是下一次循环，一般来说在当前循环完全结束后才会改变循环变量。（eg. len = r - l +1这种需要在最后操作完再进行l++或i--表示进入下一次循环，在公式前就修改了r或l会产生歧义或bug）

而for循环则控制了循环变量为固定，并且每层都不需要考虑对循环变量进行修改操作（如果操作了，要么是bug要么就是设计不合理），整层循环变量会在循环体所有逻辑执行完后才改变。



**使用场景：**

for: 步进确定，条件线性，直观不容易犯错。
1. 定长滑窗
2. 读写指针，原地修改数组
3. 基础的二叉树/图的遍历，`for(int i = 0; i < size; i++)`可用来控制层数

while: 步进不确定，或需要达到某种条件
1. 对撞双指针
2. 快慢指针，链表
3. 变长滑窗：76. 最小覆盖子串、209. 长度最小的子数组。
4. 嵌套处理
5. 二分查找   704. 二分查找

##### 13 计算罗马数字
解法1：从左往右while遍历，先判断前两位是不是做减法的特殊情况，如果是则结果累加，步进+2，continue后续操作；如果不是则继续取一位判断，结果累加，步进+1； （switch记得break和continue，不然switch会多执行）

解法2：把做减法的特殊情况更换不同字符，使用字符串替代的方法（如s = s.replace("IV","a");），最后遍历字符串相加即可

解法3：根据数学特性逐个扫描字符计算，记录当前字符值和前一字符值，如果当前字符值比前一字符值小，则`total += curvalue`；如果当前字符值比前一字符大，则说明是做减法的特殊情况，则`total += curvalue - 2*prevalue`（因为prevalue在前一次计算中被相加，所以需要减两倍）
e.g. `XIV = 10 + 1 +5 - 2*1 = 14`

##### 14 找字符串数组的最长前缀 
解法1：第一层遍历各个位置（垂直遍历，遍历值可以取最短字符长度，或者第一个字串长度，注意在比较时加上边界判断，若遍历到超出第二层那个位置的字符串长度则终止），第二层遍历所有数组。比较基准可以找第一个字符串比较，若遍历位置字符不等、遍历位置超出比较字符串长度则可以输出最长前缀，否则可继续往后append

解法2：从后往前找，遍历结构与解法1类似也是两层for，只不过第一层从后往前--，而判断则采用string.startswith(prefix)或者string.substring(0,i)这种来判断是否相同

解法3：先把字符串排序，排序后的字符串只需要找第一个和最后一个的最长前缀，思路简洁，开销基本只花在排序上。
